## 1. Запуск развёрнутым

При запуске главное окно сразу разворачивается на весь рабочий экран Windows. Имеется в виду обычное развёрнутое окно приложения; отдельный режим без рамки не запрошен.

## 2. Центрирование окон

Окна создания заявки и просчёта, карточки заявок и просчётов и другие внутренние диалоговые окна открываются по центру главного окна приложения.

## 3. Оформление смены статуса

Сделать смену статуса непосредственно в таблице графически более выразительной и удобной, в стиле приложения. Конкретный вид элемента выбора пока не утверждён. Перечень статусов, их цвета и правила переходов сохраняются.

## 4. Просчёты выбранного менеджера при создании заявки

При выборе менеджера в форме создания заявки список просчётов показывает только просчёты этого менеджера, доступные для привязки по действующим правилам. Просчёты остальных менеджеров не отображаются.

При смене выбранного менеджера список должен обновляться под нового менеджера.

Формат пункта в списке: номер → дата создания → менеджер.
Пример: №00005 — 01.10.2026 — Сергей Головко.

Заявка без привязанного просчёта остаётся допустимой. Это требование относится к форме создания заявки; свободное редактирование менеджера уже существующей заявки не отменяется.
