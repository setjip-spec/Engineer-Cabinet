# Состояние — версия 1.1.1 готова к пользовательской проверке

Пользователь 05.10.2026 поручил три изменения фильтрации: добавить «Активные + готовые», сделать множественный выбор статусов с галочками и сохранять фильтры между сессиями. Актуальные правила — раздел 30 SPEC.md.

## Реализовано

1. В «Показать» заявок добавлен режим «Активные + готовые»: Создан / В работе / Пауза / Готово; завершённые заявки исключаются.
2. Фильтр «Статус» заменён на множественный список с галочками. Можно одновременно включать любые статусы; есть «Выбрать все» и «Снять все».
3. «Сбросить фильтры» возвращает исходное состояние, включая все статусы.
4. Фильтры заявок и просчётов сохраняются в SQLite и восстанавливаются при следующем запуске: «Показать», менеджер, номер, комментарий и набор статусов.
5. Старый внутренний порядок фильтров сохранён для совместимости с функциями и тестами версии 1.1.
6. Версия приложения повышена до 1.1.1. Схема рабочих таблиц SQLite, папки, заявки, просчёты, суммы и формула 3% не менялись.
