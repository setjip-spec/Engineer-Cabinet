## Реализовано

1. Главное окно запускается развёрнутым.
2. Карточки, создание, выбор статуса, журнал и подтверждение удаления центрируются относительно приложения с учётом монитора. Длинные карточки прокручиваются, действия закреплены снизу.
3. Цветной выбор статуса с отметкой текущего. Завершение по-прежнему требует суммы и месяца.
4. При создании заявки — доступные просчёты выбранного менеджера в формате номер — дата — менеджер. Смена менеджера обновляет список и сбрасывает несовместимый выбор.
5. Удаление из меню строки и карточки — только после подтверждения. Отмена сохраняет запись и файлы. Удаляется собственная папка; связанная запись и её папка сохраняются. Завершённые заявки защищены.
6. Бонусы 3% разделены на активные и готовые суммы; завершённые учитываются в отчётности.
7. Поиск по части комментария без учёта регистра, совместимый с остальными фильтрами.
8. Поиск по номеру с первой цифры, по любой части номера, без Enter.

Схема SQLite, рабочие папки, ставка и округление сохранены. Исправлена также невидимость текста в выпадающем списке при фокусе.
