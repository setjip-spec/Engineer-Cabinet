## Изменения относительно v0.2
Четыре рабочих статуса и завершение заявки; фиксированные цвета, сортировка по номеру, поиск по окончанию. Связь один к одному с изменяемой привязкой. Папки в D:, четыре менеджера, повторное использование удалённых номеров. 3%, округление до рубля, отчёт по месяцу закрытия и автоматически сохранённому году. Удаление собственной папки вместе с записью после подтверждения; завершённые заявки удалять нельзя. Сроки исключены; комментарии в обоих типах; деньги только в заявках.

## Проверки
Выполнена структурная проверка XML двух схем: уникальные ID, существующие источники/приёмники стрелок, достижимость узлов от начала, выходы всех неконечных узлов, подписанные пары выходов развилок, графические сведения.
Проверены на уровне требований: дубликат 123/00123 запрещён; пустая сумма не позволяет закрытие, 0 позволяет; удалённый номер доступен повторно у того же менеджера; пауза возвращается в работу.
Финансовый пример: 1016.60 → 1017; 1017 × 0.03 = 30.51 → 31 рубль. Итог месяца складывается из округлённых значений.
Это не тесты приложения, его пока нет. Открытие/повторное сохранение пользователем в Camunda и экспорт картинок пока не проверены.
