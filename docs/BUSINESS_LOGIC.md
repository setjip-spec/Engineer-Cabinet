## 1. Общая основа
Один инженер на одном ПК, без CRM-синхронизации и зависимости от Google. Пользователь сам размещает файлы и работает в AutoCAD. Клик по строке открывает карточку, отдельное действие — папку. Комментарий заявки редактируется в строке и совпадает с полем карточки. Заказчик не обязателен. Рабочие документы — GitHub.

## 2. Статусы и цвета — утверждено
| Статус | Цвет | Правило |
| --- | --- | --- |
| Создан | Белый | Автоматически при создании просчёта или заявки |
| В работе | Синий | Начало/возобновление работы отмечается вручную |
| Пауза | Оранжевый | Только нехватка задания или исходных данных; обычный перерыв статус не меняет |
| Готово | Светло-зелёный | Вручную после окончания инженерной работы |
| Завершённая | Тёмно-зелёный | Только заявка; автоматически при указании месяца закрытия из любого рабочего статуса |

У обоих типов допустимы «В работе → Пауза → В работе» и «Готово → В работе» для доработки.
«Готово» у заявки без закрытия не означает полное завершение.
Завершённую заявку нельзя вернуть в работу или снять закрытие. Сумму и связь с просчётом изменять разрешено; месяц закрытия исправлять разрешено.
Наличие файлов не устанавливает готовность автоматически.

## 5. Связь просчёт–заявка — утверждено
Необязательная связь один к одному: у заявки максимум один просчёт, у просчёта максимум одна заявка одновременно. Заявка может существовать без просчёта.
Файлы просчёта остаются в исходной папке. В заявке хранится ссылка на неё; копирования или перемещения нет. У заявки остаётся собственная папка.
Связь можно добавить, заменить или убрать в любой момент, в том числе у завершённой заявки. Файлы и папки остаются на месте; после снятия связи просчёт доступен для другой заявки.
При заполнении/выборе просчёта в заявке его менеджер подставляется автоматически. Пользователь может вручную изменить менеджера только в заявке; менеджер исходного просчёта не меняется. Без просчёта менеджер выбирается вручную.
Пользователь просил подсвечивать подставленного менеджера; точное оформление определяется на этапе визуала.
Связь сама по себе не закрывает просчёт и не меняет его рабочий статус.

## 6. Заработок и закрытие — утверждено
Единая ставка: заработок по заявке = общая сумма × 3%.
Общую сумму можно изменять в любой момент, включая завершённую заявку. Заработок и месячный итог автоматически пересчитываются.
При закрытии пользователь указывает только месяц. Год автоматически берётся текущий на момент закрытия и сохраняется; смена календарного года старые записи не изменяет. Ручной выбор другого года не утверждён.
Выбор месяца из любого рабочего статуса автоматически ставит «Завершённая».
За каждый месяц и год хранится перечень заявок, сумма каждой заявки, её заработок 3% и общий заработок.
При исправлении месяца закрытия заявка остаётся завершённой, её заработок переносится между месяцами с пересчётом обоих итогов. Сохранённый год не меняется.
Пример проверки (не выполнен в приложении): 100000 × 3% = 3000; после изменения суммы на 120000 заработок = 3600, месячный итог увеличивается на 600.
Отчёт отражает заработок; отдельный учёт фактических выплат пользователем не определён. Правила валюты, точности и округления ещё открыты.
