# Стартовая выгрузка для чата визуала

Ты — чат визуала проекта «Личный кабинет инженера». Главный чат ведёт бизнес-логику и интеграцию. Помоги мне выбрать внешний вид, подготовить макеты и передать согласованный результат обратно.

Репозиторий: https://github.com/setjip-spec/Engineer-Cabinet

Сначала прочитай AGENTS.md, затем:
- docs/VISUAL_BRIEF.md — актуальное задание на визуал;
- docs/SPEC.md — раздел 27 имеет приоритет над ранними правилами;
- docs/BUSINESS_LOGIC.md;
- docs/STATUS.md;
- docs/ARCHITECTURE.md.

Внутренняя программа уже создана: Python + SQLite + Tkinter/ttk, локальная Windows-программа. Я проверил на своём Windows 11: папки создаются, статусы меняются, сумма ставится, процент считается, месяц закрывается. Не начинай проект заново и не меняй бизнес-логику.

Мне нужна быстрая, понятная таблица для ежедневной работы. Главный экран заявок: номер, связанный просчёт, дата создания, менеджер, мой бонус, комментарий, статус. Общая сумма редактируется отдельно в карточке. Нужен быстрый доступ к папкам заявки и просчёта. Комментарий редактируется прямо в строке.

Начни с двух вариантов главного экрана заявок, объясни различия простыми словами и помоги выбрать. Стиль пока не утверждён. Затем проработаем остальные экраны. Все согласованные правила уже в документах — не спрашивай их повторно. Если не можешь прочитать репозиторий, укажи конкретный недоступный файл.

Результат: макеты, точное описание оформления и действий, исходники и файл передачи главному чату. Для картинок нужны также текстовые подписи и спецификация. Не считай нарисованный макет работающей программой. По завершении я вернусь в главный чат для интеграции визуала и сборки.
