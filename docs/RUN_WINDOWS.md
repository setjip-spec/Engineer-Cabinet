# Первый запуск на Windows 11

Это рабочий внутренний прототип с простыми формами. Финальное оформление и установщик появятся после проверки.

## Готовый exe

Открыть GitHub → Actions → Windows prototype → успешный запуск → Artifacts → EngineerCabinet-Windows.
Распаковать ZIP полностью. Открыть EngineerCabinet.exe внутри распакованной папки. Не переносить отдельно exe от папки _internal.
Python, VS Code и Codex для запуска собранного exe не нужны. Приложение пока не подписано цифровой подписью.

При первом запуске указать общую папку, например D:\\Кабинет инженера. Все данные и рабочие файлы будут внутри неё. Для первого испытания использовать отдельную пустую папку D:\\Кабинет инженера — тест; не переносить настоящие задания до проверки.

## Запуск из VS Code / Codex

Открыть репозиторий на компьютере. Python 3.12 для Windows должен включать Tcl/Tk.
В терминале проекта:

```powershell
py -3.12 main.py
```

Зависимостей pip для запуска из исходников нет. Если запускается другая база:

```powershell
py -3.12 main.py --choose-root
```

При подключении локального Codex дать ему задачу: «Прочитай AGENTS.md, docs/SPEC.md (последний раздел), docs/STATUS.md и docs/RUN_WINDOWS.md. Проверь Python/Tk, запусти main.py на отдельной тестовой папке. Не используй реальные задания для тестового удаления».

## Что проверить

1. Создать просчёты двух менеджеров; проверить пятизначный номер и обе подпапки.
2. Положить тестовый DWG, открыть папку, изменить статус и комментарий (двойной щелчок по ячейке, Enter сохраняет, Escape отменяет).
3. Создать заявку, связать с просчётом. Проверить обе кнопки папок; файлы просчёта не копируются.
4. В карточке задать сумму 1016,60; после сохранения сумма 1017, заработок 31.
5. Указать месяц; заявка завершена. Открыть Историю заработка, проверить месяц и переход в заявку.
6. Исправить сумму завершённой заявки, увидеть новый итог и журнал изменения. Пустая сумма запрещена; 0 разрешён.
7. Перезапустить: записи и папки сохранены.
8. На тестовых файлах проверить переименование и подтверждённое удаление. Завершённую заявку удалить нельзя.
9. В настройках создать копию, проверить восстановление отдельно.

Вкладка «История заработка» содержит все сохранённые месяцы и заявки. Сумма на основном экране скрыта, редактируется в карточке. Журнал фиксирует исправления.

## Копии и восстановление

Копия базы и всех зарегистрированных файлов создаётся раз в 7 дней, когда приложение работает; максимум 3 ZIP. Пропущенная копия выполняется при следующем запуске. Файлы, открытые/изменяемые AutoCAD, могут потребовать повторить копию после сохранения и закрытия.

Восстановление через диалог выбора ZIP и новой пустой папки:

```powershell
py -3.12 main.py --restore
# Для готовой сборки:
.\\EngineerCabinet.exe --restore
```

После восстановления открыть новую папку через --choose-root. Исходная база и внешние папки не затираются. При ошибке восстановления новая папка может содержать частичный результат; для следующей попытки выбрать другую пустую папку. Копии на том же диске не заменяют хранение дополнительной копии на другом носителе.

## Ограничения первого выпуска

- Финальный визуал и установщик ещё не сделаны; сборка переносимая.
- При файловой операции или резервировании окно отвечает, но новые операции ждут её окончания.
- Символические ссылки/junction и общие папки нельзя назначать собственной папкой записи.
- Работа с большими реальными DWG и отзывчивость на полном объёме проверяются на ПК.
- Сначала локальная проверка, затем перенос реальных заданий и визуальный этап.
