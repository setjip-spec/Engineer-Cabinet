# Личный кабинет инженера

Личная программа для просчётов, заявок, комментариев, сумм, бонусов и папок заданий на одном компьютере.

**Состояние:** подготовка требований. Исходники приложения и Windows-установщик пока не созданы.

- [ТЗ](docs/SPEC.md)
- [Бизнес-логика и открытые решения](docs/BUSINESS_LOGIC.md)
- [Предлагаемая архитектура](docs/ARCHITECTURE.md)

- [Состояние и порядок разработки](docs/STATUS.md)
- [Регламент для агентов](AGENTS.md)

Предложение: Tauri 2, React, TypeScript, Rust и SQLite. Стек ещё нужно зафиксировать перед реализацией. Работа приложения не зависит от Google.

GitHub Pages — возможный предпросмотр интерфейса. Доступ к папкам рабочего компьютера обеспечивает устанавливаемое приложение.

Репозиторий публичный. Рабочая база и файлы клиентов хранятся вне него.
