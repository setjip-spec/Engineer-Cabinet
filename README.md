# Личный кабинет инженера

Первый локальный рабочий прототип для Windows 11: просчёты, заявки, папки, комментарии, заработок 3% и месячная история. Простой интерфейс предназначен для проверки внутренней части; финальный визуал — следующий этап.

- [Как запустить и проверить](docs/RUN_WINDOWS.md)
- [Состояние и проверки](docs/STATUS.md)
- [ТЗ: последние решения в разделе 27](docs/SPEC.md)
- [Бизнес-логика](docs/BUSINESS_LOGIC.md)
- [Архитектура](docs/ARCHITECTURE.md)
- [Схемы и передача](docs/processes/HANDOFF_TO_MAIN.md)

Python 3.12 + SQLite + Tkinter/ttk. Запуск исходников: `python main.py`. Проверки: `python -m unittest discover -s tests -v`.

GitHub Actions → Windows prototype собирает переносимую папку с EngineerCabinet.exe. Работа приложения локальная, без Google и сервера. GitHub Pages не запускает настольную программу.

Все рабочие данные находятся в общей папке, по умолчанию `D:\Кабинет инженера`. Репозиторий содержит только исходники и документацию; клиентские файлы и рабочую базу сюда не помещать.
